# Обзор презентации: RAG-система по истории Римской империи

## Идея проекта за 30 секунд (вступление для любого докладчика)

> Мы построили **умную систему вопросов-ответов** по Римской империи. Она не «гуглит» по словам, а **понимает смысл** вопроса, находит нужные места в нашем 11-страничном историческом документе и просит нейросеть написать ответ **строго по этим фактам и с цитатами**. Это называется **RAG — Retrieval-Augmented Generation**: «поиск + генерация». Так мы получаем точные, проверяемые ответы без «галлюцинаций» нейросети.

## Как устроена система (общая схема — общий слайд)

```
                ЧАСТЬ 1                  ЧАСТЬ 2                       ЧАСТЬ 3

PDF ──► │ извлечь · очистить│──►│ эмбеддинги (MiniLM)     │   │ промпт + контекст       │
        │ нарезать на чанки │   │ FAISS-индекс            │   │ Gemini / Claude         │
        └──────────────────┘   │ поиск top-k по смыслу   │──►│ ответ с цитатами        │
          «источник правды»     └────────────────────────┘   │ CLI + веб-приложение    │
                                   «семантический поиск»       └────────────────────────┘
                                                                  «ответ для человека»
   вопрос пользователя ───────────────────────────────────────────────┘
```

## Тайминг (≈12 минут + демо)

1. **Вступление (1 мин)** — любой: проблема и идея RAG (текст выше) + общая схема.
2. **Часть 1 (3 мин)** — как готовим документ и режем на чанки; почему качество источника = качество ответа.
3. **Часть 2 (3 мин)** — что такое эмбеддинги, как FAISS ищет по смыслу; метрика 100% retrieval accuracy.
4. **Часть 3 (3 мин)** — промпт-инжиниринг, вызов LLM, цитаты; интерфейсы.
5. **Живое демо (2 мин)** — веб-приложение: задать вопрос, показать ответ + источники, включить режим «с RAG / без RAG».
6. **Итоги/вопросы (1 мин)** — чему научились: «вся сложность RAG — в подготовке и поиске; нейросеть нужно лишь *ограничить* контекстом и *заставить* цитировать».

## Главный вывод проекта (финальный слайд)

> **RAG = надёжность LLM.** Нейросеть сама по себе может ошибаться и выдумывать. Добавив этап поиска по проверенному источнику, мы получаем ответы, которые **точны, актуальны и проверяемы по цитатам**. Большая часть инженерной работы — это не сама нейросеть, а подготовка данных (Часть 1) и качественный поиск (Часть 2).
